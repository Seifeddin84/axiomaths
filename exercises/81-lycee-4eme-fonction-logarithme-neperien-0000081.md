1. Démontrer que, pour tout réel $x > 0$ ;
   $$\frac{x-1}{x} \le \ln x \le x-1$$
   En déduire que : pour tout $x \in ]0, 1[$ ; $\ln(1+x) < x < -\ln(1-x)$

2. Soit la suite $(u_n)$ définie pour $n \in \mathbb{N}^*$ par :
   $$u_n = \frac{1}{n} + \frac{1}{n+1} + \dots + \frac{1}{n+nk} \text{ avec } k \text{ un entier de } \mathbb{N} \text{ donné.}$$

   a. Montrer que : pour tout $n \in \mathbb{N} ; n \ge 2$ on a :
      $$\ln\left(k+1+\frac{1}{n}\right) < u_n < \ln\left(k+1+\frac{k+1}{n-1}\right)$$

   b. En déduire que la suite $(u_n)$ converge et déterminer sa limite.
