Pour chaque question, une seule des trois réponses proposées est correcte. Cocher la bonne réponse.

1. La moyenne de la série $2\ ;\ 5\ ;\ 5\ ;\ 8\ ;\ 10$ est :

   - [ ] $5$

   - [ ] $6$

   - [ ] $8$

2. Une série a pour écart type $\sigma = 2$. On ajoute $3$ à chacune de ses valeurs. Le nouvel écart type est :

   - [ ] $2$

   - [ ] $5$

   - [ ] $6$

3. Une série a pour variance $V = 4$. On multiplie chacune de ses valeurs par $3$. La nouvelle variance est :

   - [ ] $4$

   - [ ] $12$

   - [ ] $36$

4. Une série de $30$ valeurs est rangée par ordre croissant. D'après la règle du cours, le premier quartile $Q_1$ est la valeur de rang :

   - [ ] $7$

   - [ ] $7{,}5$

   - [ ] $8$

5. Lequel de ces indicateurs est le moins sensible aux valeurs extrêmes ?

   - [ ] la moyenne

   - [ ] l'écart type

   - [ ] la médiane

6. Le point moyen du nuage formé des points $A(1\,;\,2)$, $B(3\,;\,4)$ et $C(5\,;\,9)$ est :

   - [ ] $G(3\,;\,4)$

   - [ ] $G(3\,;\,5)$

   - [ ] $G(9\,;\,15)$

---

## Solution

1. **Réponse : $6$.** $\overline{x} = \dfrac{2 + 5 + 5 + 8 + 10}{5} = \dfrac{30}{5} = 6$. (La valeur $5$ est le mode et aussi la médiane, pas la moyenne.)

2. **Réponse : $2$.** Ajouter une même constante déplace toutes les valeurs d'un bloc : les écarts à la moyenne ne changent pas, donc l'écart type non plus.

3. **Réponse : $36$.** Si $y_i = 3x_i$, alors $\sigma_y = 3\sigma_x$, donc $V_y = 3^2 \times V_x = 9 \times 4 = 36$. Le piège est de répondre $12$ : la variance est multipliée par le **carré** du coefficient.

4. **Réponse : $8$.** $\dfrac{30}{4} = 7{,}5$ n'est pas un entier ($30$ n'est pas un multiple de $4$) : on prend l'entier immédiatement supérieur, $8$.

5. **Réponse : la médiane.** Elle ne dépend que du rang des valeurs. La moyenne et l'écart type utilisent toutes les valeurs : une seule valeur extrême peut les modifier fortement.

6. **Réponse : $G(3\,;\,5)$.** $\overline{x} = \dfrac{1 + 3 + 5}{3} = 3$ et $\overline{y} = \dfrac{2 + 4 + 9}{3} = 5$.
