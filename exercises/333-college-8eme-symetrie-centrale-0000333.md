1. أتمم الجدول :

   | الشكل | يقبل مركز تناظر ؟ | عدد محاور التناظر |
   |---|---|---|
   | متوازي أضلاع (غير مستطيل وغير معين) |  |  |
   | مستطيل (غير مربع) |  |  |
   | معين (غير مربع) |  |  |
   | مثلث متقايس الضلعين (غير متقايس الأضلاع) |  |  |
   | شبه منحرف عادي |  |  |
   | دائرة |  |  |

2. السداسي $ABCDEF$ مرسوم على الشبكة. بين أن له مركز تناظر $O$ يُطلب تعيينه.

   ![Figure : مراكز التناظر ومحاوره](/exercises/images/333-college-8eme-symetrie-centrale-0000333-1.png)

3. عيّن محوري تناظر للسداسي $ABCDEF$.

4. هل كل شكل يقبل مركز تناظر يقبل محور تناظر ؟ وهل العكس صحيح ؟

---

## Solution

1.
   :::property[مركز تناظر شكل]
   $O$ مركز تناظر شكل $\mathcal{F}$ معناه **مناظر $\mathcal{F}$ بالنسبة إلى $O$ هو $\mathcal{F}$ نفسه**.
   :::

   | الشكل | يقبل مركز تناظر ؟ | عدد محاور التناظر |
   |---|---|---|
   | متوازي أضلاع (غير مستطيل وغير معين) | نعم | 0 |
   | مستطيل (غير مربع) | نعم | 2 |
   | معين (غير مربع) | نعم | 2 |
   | مثلث متقايس الضلعين (غير متقايس الأضلاع) | لا | 1 |
   | شبه منحرف عادي | لا | 0 |
   | دائرة | نعم | لا نهاية |

   لمتوازي الأضلاع (والمستطيل والمعين) مركز هو نقطة تقاطع قطريه ؛ وللدائرة مركز هو مركزها.

2. نبحث عن نقطة تكون منتصف القطع الواصلة بين الرؤوس المتقابلة. على الشبكة : من $A$ إلى $D$ ننتقل 3 وحدات يمينا و 4 إلى الأعلى ؛ من $B$ إلى $E$ : 3 وحدات يسارا و 4 إلى الأعلى ؛ من $C$ إلى $F$ : 5 وحدات يسارا. في الحالات الثلاث تقع النقطة $O$ (المبينة على الشكل) في منتصف الانتقال، أي $O$ منتصف كل من $[AD]$ و $[BE]$ و $[CF]$. إذن $S_O(A)=D$ و $S_O(B)=E$ و $S_O(C)=F$ ، فمناظر السداسي هو $DEFABC$ أي السداسي نفسه. **$O$ مركز تناظر السداسي**.

   ![Figure : مراكز التناظر ومحاوره](/exercises/images/333-college-8eme-symetrie-centrale-0000333-2.png)

3. المستقيم العمودي المنصّف لـ $[AB]$ (الذي يمر من $O$) يحوّل $A$ إلى $B$ و $F$ إلى $C$ و $E$ إلى $D$ : إنه محور تناظر. والمستقيم الأفقي المار من $O$ يحوّل $A$ إلى $E$ و $B$ إلى $D$ و $F$ و $C$ كل منهما إلى نفسه : إنه محور ثانٍ. **المحوران متعامدان ويتقاطعان في $O$**.

4. لا في الاتجاهين :

   - متوازي الأضلاع العادي له مركز تناظر ولا محور له.

   - المثلث المتقايس الضلعين له محور تناظر ولا مركز له.

   **الفكرة :** لا تلازم بين المركز والمحور ؛ وإذا كان لشكل محوران متعامدان فنقطة تقاطعهما مركز تناظره (كما في السداسي والمعين والمستطيل).
