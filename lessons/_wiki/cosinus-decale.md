---
theorem: "Une somme de cosinus et de sinus est un cosinus décalé"
---

:::redaction
On pose $r = \sqrt{a^2 + b^2} > 0$ ; alors $\left(\dfrac ar\right)^2 + \left(\dfrac br\right)^2 = \dfrac{a^2 + b^2}{r^2} = 1$.
Donc le point $\left(\dfrac ar\,;\dfrac br\right)$ est sur le cercle trigonométrique : il existe $\varphi$ tel que $\cos\varphi = \dfrac ar$ et $\sin\varphi = \dfrac br$.
Pour tout réel $x$, $a\cos x + b\sin x = r\big(\cos\varphi\cos x + \sin\varphi\sin x\big)$.
D'après la formule d'addition, $\cos\varphi\cos x + \sin\varphi\sin x = \cos(x - \varphi)$.
D'où $a\cos x + b\sin x = r\cos(x - \varphi)$.
:::
