---
theorem: "Équation réduite"
---

:::redaction
On note $D : x = k$ et $K(k, 0)$ ; les sommets $S(a, 0)$ et $S'(-a, 0)$ sont sur la conique, donc vérifient $MF = e\cdot MK$.
Pour une ellipse, $a - c = e(k - a)$ et $a + c = e(k + a)$ ; pour une hyperbole, $c - a = e(a - k)$ et $c + a = e(a + k)$.
Dans les deux cas, en ajoutant puis en retranchant, on obtient $c = ea$ et $k = \dfrac ae = \dfrac{a^2}{c}$.
Soit $M(x, y)$ et $H(k, y)$ son projeté sur $D$ ; $M \in \mathcal C \iff MF^2 = e^2MH^2$.
C'est-à-dire $(x - c)^2 + y^2 = \dfrac{c^2}{a^2}\left(x - \dfrac{a^2}{c}\right)^2 = \dfrac{c^2x^2}{a^2} - 2cx + a^2$.
Les termes $-2cx$ se simplifient : $\left(1 - \dfrac{c^2}{a^2}\right)x^2 + y^2 = a^2 - c^2$.
Comme $e \neq 1$, $a^2 - c^2 \neq 0$, et en divisant : $\dfrac{x^2}{a^2} + \dfrac{y^2}{a^2 - c^2} = 1$.
Pour une ellipse, $a^2 - c^2 = b^2 > 0$ ; pour une hyperbole, $a^2 - c^2 = -b^2 < 0$, d'où $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$.
:::
