---
theorem: "Équation az^2 + bz + c = 0"
---

:::redaction
Comme $a \neq 0$, on écrit la forme canonique : $az^2 + bz + c = a\left[\left(z + \dfrac{b}{2a}\right)^2 - \dfrac{\Delta}{4a^2}\right]$.
Or $\dfrac{\Delta}{4a^2} = \left(\dfrac{\delta}{2a}\right)^2$, donc $az^2 + bz + c = a\left(z + \dfrac{b - \delta}{2a}\right)\left(z + \dfrac{b + \delta}{2a}\right) = a(z - z_2)(z - z_1)$.
Un produit est nul si et seulement si l'un de ses facteurs l'est, et $a \neq 0$.
D'où les solutions sont $z_1 = \dfrac{-b - \delta}{2a}$ et $z_2 = \dfrac{-b + \delta}{2a}$, confondues si $\delta = 0$.
Enfin $z_1 + z_2 = \dfrac{-2b}{2a} = -\dfrac ba$ et $z_1z_2 = \dfrac{b^2 - \delta^2}{4a^2} = \dfrac{4ac}{4a^2} = \dfrac ca$.
:::
